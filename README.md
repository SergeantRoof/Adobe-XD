## 🧠 Overview

Adobe XD is a vector-based user experience design tool developed and published by Adobe. It was first announced as Project Comet in October 2015 and reached general availability in 2017. Versions exist for macOS and Windows, with companion apps for iOS and Android for previewing work on devices.

The program is used to design user interfaces for web and mobile applications, create wireframes, and link artboards into interactive prototypes. It fits into a design workflow alongside other Adobe applications, and can open files from Illustrator, Photoshop, Sketch and After Effects. Prototypes can be shared with password protection and previewed on supported mobile devices.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🔁 Repeat grid | Creates a grid of repeating items such as lists and photo galleries. |
| 🔗 Linked prototypes | Builds animated prototypes by linking artboards together. |
| 📱 Mobile preview | Previews prototypes directly on supported iOS and Android devices. |
| 📂 File interoperability | Opens files from Illustrator, Photoshop, Sketch and After Effects. |
| 🧩 Content-aware layout | Adjusts and moves layout elements automatically as content changes. |
| 🔒 Password-protected sharing | Sends prototypes with password protection for controlled disclosure. |
| 💬 Collaboration links | Connects to tools and services such as Slack and Microsoft Teams. |
| 🖥️ Cross-platform files | Moves work between macOS and Windows with automatic adjustment. |

## Additional Information for Windows Users

Adobe announced in June 2023 that XD was discontinued as a purchasable item, and stated it would not further invest in the product following the failed acquisition of Figma. Existing users should check current availability and support terms with Adobe before relying on it for new projects.

The tool is distributed through Adobe Creative Cloud, so a subscription and an Adobe account are normally required. Mobile preview apps are separate downloads for iOS and Android.
